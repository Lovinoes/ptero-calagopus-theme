# ptero-calagopus-theme
The classic [Pterodactyl](https://github.com/pterodactyl/panel) look for [Calagopus](https://github.com/calagopus/panel). Only the user side is themed, the admin area stays stock.

> [!WARNING]
> This theme is fully vibecoded: it was written by AI (Claude Opus 5.5, partially using the ponytail skill) and only parts of it were reviewed by a human. Use it at your own risk.

Needs Calagopus 1.2.10 or newer. See [FEATURES.md](FEATURES.md) for what it changes and [EXTENSIONS.md](EXTENSIONS.md) if you write extensions.

## Install
Grab `dev_lovinoes_pterodactyl.c7s.zip` from the [latest release](https://github.com/Lovinoes/ptero-calagopus-theme/releases/latest) and follow [Installing Extensions](https://calagopus.com/docs/panel/extensions/installing-extensions).

## Build
```bash
node scripts/package.mjs
```
Needs Node.js 24+. The archive ends up in `dist/`.

# ptero-calagopus-theme
Makes the user side of [Calagopus](https://github.com/calagopus/panel) look like the classic [Pterodactyl](https://github.com/pterodactyl/panel) panel. The admin area stays stock.

> [!WARNING]
> This theme is fully vibecoded: it was written by AI (Claude Opus 5.5, high effort) and only parts of it were reviewed by a human. Use it at your own risk.

Supports Calagopus 1.2.9 and 1.2.8. See [FEATURES.md](FEATURES.md) and [EXTENSIONS.md](EXTENSIONS.md).

## Installation
Download `dev_lovinoes_pterodactyl.c7s.zip` from the [latest release](https://github.com/Lovinoes/ptero-calagopus-theme/releases/latest) and follow [Installing Extensions](https://calagopus.com/docs/panel/extensions/installing-extensions).

## Building
`node scripts/package.mjs` (Node.js 24+) writes the archive to `dist/`.
